## Laboratorio 2 - Arreglos y excepciones, AGENCIA DE DETECTIVES – CASO MISTERIOSO
 
Programa en Java para administrar casos de una agencia de detectives.

Permite registrar, consultar, modificar y eliminar ubicaciones y pistas,
además de generar reportes.

Utiliza un arreglo de cinco ubicaciones, un ArrayList de pistas y manejo
de excepciones.
